# CodeAlpha E-Commerce Website

A full-stack E-Commerce website built using:

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Express.js (Node.js)

Database:
- Firebase Firestore

Authentication:
- Firebase Authentication

## Features

- User Registration
- User Login
- Protected Routes
- Product Listings
- Product Details Page
- Shopping Cart
- Checkout System
- Order Processing
- Express Backend APIs
- Responsive Design

## Project Structure

## Backend APIs

### Products API

GET

/api/products

### Orders API

POST

/api/orders

## Installation

### Frontend

Run using Live Server.

### Backend

Open terminal:

cd server

Install packages:

npm install

Run backend:

npm run dev

Backend runs at:

http://localhost:5000
